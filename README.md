i built and published a Chrome extension that watches Discord for new Minecraft skill-test queues and helps players join quickly. it now has **300+ users**.

**links:** [Chrome Web Store](https://chromewebstore.google.com/detail/mctiers-queue-sniper-watc/aibcfnkajkoandabcpbebgaijomadkjn) · [case study](https://github.com/AndrejRodic/queue-monitor-showcase)
